## 与现有账号接口的兼容

- 验证码接口为 /api/account/checkCode，响应字段为 check_code 和 check_code_key。
- 注册把原始密码通过 HTTPS 表单发给后端；后端沿用当前逻辑保存其 MD5 摘要。
- 登录按现有 Electron 客户端协议发送 MD5(password)。这是兼容旧后端的过渡协议，不是最终密码存储方案。
- sessionStorage 仅保存当前标签页所需的账号公开资料，不保存登录 token；后端 HttpOnly Cookie 管理 REST 登录态，WebSocket 票据 60 秒单次有效。
- 当前账号注册使用图片验证码，没有邮件验证码。

## AI 流式回复

AI 联系人使用后端已有的 `/chat/sendMessage` 和 WebSocket 类型 14/15/16。网页把累计片段更新在同一条消息中；状态 1 表示完成、2 表示已停止、3 表示生成失败。用户可停止自己的生成，已输出的部分文本会保存在服务器历史中。启用 AI 时须在后端配置 `WETALK_AI_ENABLED=true`、`WETALK_AI_MODEL=openai` 以及 OpenAI 兼容提供方参数。

## 网页版本提示

登录后网页用 `VITE_WEB_VERSION` 调用后端 `/app/checkUpdate`，显示已发布版本号和更新说明。HTTP/HTTPS 外链会在新标签页打开，并使用安全链接属性；本地桌面安装包只展示说明，不作为网页下载提供。没有更高版本或检查失败时不打断聊天。后端始终按登录会话判断灰度资格，兼容保留的请求 `uid` 不参与权限判断。
