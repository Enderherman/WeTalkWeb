## 页面验收标准

- 历史、版本提示和会话工具栏同时存在时输入框可见，消息区内部滚动。
- 手机管理标题/导航及卡片按钮可换行，目标路由和标题核对后测量宽度。
- 登录错误、表头、只读控件和下载设置使用有效主题颜色；登录失败留在登录页。
- WebKit 菜单点击不会被空目标失焦提前删除；外部点击、键盘离开和窗口失焦仍正常关闭。
- 新聊天/目录/搜索使用服务器权威会话，关闭和取消返回可见焦点；等待 INIT 可取消/超时重试。

这些标准对应本轮发现并修复的具体问题；变更记录集中在 [更新日志](../CHANGELOG.md)，布局、会话归属和卸载原因分别见对应专题。
