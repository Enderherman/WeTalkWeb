# 管理员版本发布

入口：管理员页面的「版本发布」，路径 `/admin/updates`。普通用户由路由守卫拦截，后端五个发布管理接口仍独立校验管理员权限。

## 功能

- 分页列表、空列表、加载失败与手动重试。
- 新增与编辑草稿：三段数字版本号、逐行更新说明、Windows `.exe` 安装包或 HTTP/HTTPS 外链。
- 编辑已有本地包草稿时，未选择新文件会保留原包；新增本地版本必须选择非空安装包。
- 选择灰度账号、全量发布或撤回草稿；操作需在表单内明确确认。灰度编号去重，以逗号/换行分隔。
- 已发布版本不能直接编辑或删除，须先撤回；删除草稿有二次确认。
- 请求失败保留表单与输入，避免重复提交。弹窗支持 Escape、Tab 焦点约束及返回入口。
- 与桌面管理接口共用 `/app/loadUpdateList`、`saveUpdate`、`postUpdate`、`deleteUpdate`，安装包为 multipart 上传，无短请求超时。
