# 管理员版本管理

[首页](../README.md) · [更新日志](../CHANGELOG.md) · [REST 契约](api-inventory.md)

管理员从账号菜单进入 `/admin/updates`。Web 展示版本说明；Windows 安装包由桌面端下载。路由守卫和后端权限分别校验，普通用户不能通过手工导航取得管理权限。

## 操作流程

1. 在分页列表新增草稿，填写三段数字版本号和逐行说明，选择本地 `.exe` 或 HTTP/HTTPS 外链。
2. 草稿可编辑；已有本地包未选新文件时保留原包，新草稿必须提供非空文件。
3. 确认灰度账号名单后灰度发布，或确认全量发布；名单按逗号/换行拆分、去重。
4. 已发布记录须先撤回草稿，才能编辑或确认删除。

列表加载失败可重试，请求失败保留表单并阻止重复提交。弹窗支持 Esc、Tab 焦点约束和关闭后焦点返回。

## 校验与权限

| 项目 | 规则 |
|---|---|
| 版本号 | 三段数字，最多 10 字符；按数字比较，`1.10.0` 高于 `1.9.9` |
| 说明 / 外链 | 最多 500 / 200 字符；外链只接受 HTTP/HTTPS |
| 本地包 | 非空 `.exe`，最多 500 MiB；multipart 上传不采用短请求超时 |
| 灰度名单 | 规范化后最多 1000 字符；服务端按当前身份判断可见性 |
| 管理接口 | `loadUpdateList/saveUpdate/postUpdate/deleteUpdate` 校验管理员 |
| 查询与下载 | `checkUpdate/downloadUpdate` 校验登录与发布可见性，忽略伪造灰度身份 |

服务端通过版本唯一约束和发布锁处理并发；网页表单验证不能替代这些约束。

## 证据

2026-10-04 的组件/API/路由针对性验证 20 项通过。真实隔离 HTTP 覆盖权限、草稿不可下载、灰度身份、包字节、数字版本、撤回编辑和非法输入；实际 Chromium 页面完成新增外链草稿、灰度可见性、撤回和确认删除。五个管理页面在 390px 视口无横向溢出。

这些记录使用本机隔离后端；没有发布真实 Release、执行安装器或部署 NAS。最终功能测试汇总和精确快照边界见 [验收矩阵](feature-parity-audit.md)。
