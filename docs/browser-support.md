## 浏览器能力与降级

- 页面需要 JavaScript、WebSocket、Blob URL。认证采用 HttpOnly SameSite Strict Cookie，生产必须使用 HTTPS/WSS 和 Secure Cookie。
- IndexedDB 用于可选文字历史、待发和下载目录授权信息；不可用时仍可从服务端聊天，但不能依赖跨进程持久缓存。
- 下载默认交给浏览器。支持 `showSaveFilePicker` 时可选择单次保存位置；支持 `showDirectoryPicker` 时可显式授权目录并按账号保存句柄，写入时再检查权限，可撤销/清除。
- 不支持文件系统 API 时回退浏览器下载，不枚举任意目录。当前不请求摄像头或麦克风。
- 文字输入、菜单和对话框提供键盘焦点、Esc 返回及可访问名称；DOM/自动化证据不代替人工辅助技术验收。

## 文件边界

下表为 Web 硬上限。实际限制取当前系统配额与硬上限的较小值，后端仍做独立权限、配额和字节校验。

| 类别 | 扩展名 | 硬上限 | 行为 |
|---|---|---:|---|
| 聊天图片 | mjpeg/jpeg/jpg/png/gif/bmp/webp | 200 MiB | 鉴权下载 Blob 后预览 |
| 视频 | mp4/avi/rmvb/mkv/mov | 499 MiB | 同源 Range 播放，尝试生成 PNG 首帧 |
| 音频 | mp3/wma/flac/aac/wav/ogg/m4a/m4b | 499 MiB | 同源 Range 播放 |
| 其他文件 | 安全文件名及扩展名 | 499 MiB | 下载保存，不预览内容 |
| 用户/群头像与封面 | png/jpeg/jpg/gif/bmp/webp | 10 MiB | 选图预览；保存或关闭后释放 URL |

文件必须非空，原名最长 200 字，不含路径分隔符或控制字符；扩展名若存在，只接受 1–16 位 ASCII 字母/数字。图片扩展名和非空 MIME 必须匹配，后端继续检查签名。聊天 `.mjpeg` 作为 JPEG 别名，旧 MJPEG MIME 规范为 `image/jpeg`；空 MIME 仅按已支持扩展名补齐，原名和字节不变。

扩展名表示可上传及尝试预览，不保证各平台均能解码。Web 不做统一视频转码。首帧封面最大 640×360，8 秒内无法取帧时仍可无封面发送。媒体流使用单区间 Range；配置外部 REST API 基址时回退完整 Blob 下载，WS 仍要求同源入口。
