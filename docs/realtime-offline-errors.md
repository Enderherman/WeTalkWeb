## 错误归属

| 场景 | 当前行为 |
|---|---|
| 后台 WS 票据网络/5xx 失败 | 留给实时连接状态、重试及本地提示，保留聊天和待发 |
| `navigator.onLine=false` | 请求仍报错给调用者，但不导航到离线无法加载的错误页 |
| 当前会话 901 | 正常清理认证并返回登录 |
| 在线用户操作/首屏 API 5xx | 保留通用服务错误处理 |
| 显式断开后迟到票据失败 | 不再写入旧连接状态 |

票据策略按请求指定，不泄漏到后续请求。Wi-Fi 仍连接、浏览器仍报告在线但后端暂时不可达，也不能把现有聊天导航走。

## 文字待发

待发使用客户端 UUID 并按账号隔离。网络恢复后沿用原 UUID 重试，服务端保证幂等；用户可手动重试或删除。IndexedDB 可用时可持久保存文字待发，重新登录后恢复；缓存不可用时不承诺跨进程保留。该队列不等于所有附件都支持离线持久上传。

本人 WS 回显可先于 HTTP 确认消息；确认后清理匹配的待发与旧草稿，迟到 HTTP 不再把它们恢复为失败。细则见 [消息确认](multi-device-messages.md)。
